### 🎯 Chuẩn Đầu Ra Môn Học (Course Learning Outcomes - CLOs)

| Mã CLO | Mô Tả Chi Tiết Mục Tiêu |
|---|---|
| **CLO1** | Understand the concepts of object oriented (OO) programs to solve problems and fundamentals of object-oriented programming in Java |
| **CLO2** | Practice basic Java language syntax and semantics to write Java programs and use concepts such as variables, conditional and iterative execution methods |
| **CLO3** | Uses streams to read and write data from/to different types of sources/targets |
| **CLO4** | Discuss the benefits and the use of JAVA’s Exceptional handling mechanism |
| **CLO5** | Identify classes, objects, members of a class and relationships among them needed for a specific problem |
| **CLO6** | Explain the concept and demonstrates the use of Polymorphism, Encapsulation, Abstraction and Inheritance in java |
| **CLO7** | Discuss the principles and the use of abstract classes and interfaces in java |
| **CLO8** | Understand and implement a complete program using object array |
| **CLO9** | Explain the principles and the use of some (java collections) abstract data types (list, set, map) |
