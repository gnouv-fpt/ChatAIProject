### 🎯 Chuẩn Đầu Ra Môn Học (Course Learning Outcomes - CLOs)

| Mã CLO | Mô Tả Chi Tiết Mục Tiêu |
|---|---|
| **CLO1** | Understand thedatabase concepts and database management system software |
| **CLO2** | Understand the relation model of data and Algebraic Query Language |
| **CLO3** | Understand data normalization and apply normalization techniques in database design |
| **CLO4** | Be able to model an application’s data requirements using conceptual modeling tools like ER diagrams and design database schemas based on the conceptual model. |

| **CLO6** | Understand PL/SQL concepts and manipulate with View, Cursors, Stored Procedures, Functions, Database Triggers |
| **CLO7** | Apply the Index in database design and query optimization |
