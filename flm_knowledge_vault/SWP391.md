### ⚙️ Thông Tin Quy Chuẩn & Điều Kiện Môn Học
- **Thang điểm:** 10
- **Điểm trung bình tối thiểu để qua môn (MinAvgMarkToPass):** `5`
- **Phân bổ thời gian học (Time Allocation):** Study hour (150h) = 45h contact hours + 1h Project Presentation + 104h self-study
- **Phương pháp giảng dạy:** Lecture, Lab, Group Discussion, Presentation, Peer Review.AI-integrated tasks across all Software Development Life Cycle phases
- **Quyết định ban hành:** 377/QĐ-ĐHFPT dated 04/09/2026
- **Yêu cầu chuyên cần & sinh viên (Student Tasks):**
> - Join the team as arranged by the teacher- Select the project topic & technology stack and get approval from teacher before implementing- Attend at least 80% of contact slots in order to be accepted to the final presentation.- Analyze requirements, write user requirements, and create system diagrams with AI-assisted tools.- Design system architecture, database schema, and UI/UX wireframes using MVC, OOP, and AI suggestions.- Implement core features with AI-supported coding, apply coding standards, and manage source code in Git.- Develop and run unit/integration tests, using AI to suggest and refine test cases.- Deploy the application to staging, verify functionality, and prepare for final delivery.- Manage project progress, present milestones, and prepare high-quality reports with AI support.
- **Công cụ & phần mềm yêu cầu (Tools & Software):**
> - Requirement & Design: Miro, Lucidchart, Figma, Draw.io, ChatGPT, Gemini- Coding & Debugging: IntelliJ IDEA / VS Code / Visual Studio, GitHub Copilot, Tabnine- Database: MySQL Workbench, SQL Server Management Studio, pgAdmin-Testing: JUnit, NUnit, Postman, Selenium, AI-powered test case generators- Project Management: Jira, Trello, Notion, Git/GitHub- Deployment: Docker, Heroku, AWS / Azure / GCP, Vercel
