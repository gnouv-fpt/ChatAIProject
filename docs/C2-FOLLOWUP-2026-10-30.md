## Implemented

- Content SQL now supports importing and publishing a fixed exam template through `api/exam-templates`. Import requires unique question IDs from one published bank version, a valid passing score, and a duration within the runtime limit. Public listing excludes drafts. `api/custom-exams/from-template` creates the Redis exam using the template's fixed order, duration, and passing score. The existing exam page lists published templates. Template code/version are retained in the server-side exam and submitted snapshot.
- `api/exam-notifications` reads the authenticated user's submitted `ExamAttempts` from User SQL, so notification history remains available when the Redis inbox is deleted or expires. Kafka/Worker still delivers the existing event to Redis. This SQL read path does not constitute a transactional SQL outbox for arbitrary cross-service events.
- The exam view now returns the stored passing score, bank ID, and critical-question policy.
